# ADR-002 — 第一版采用 2D 模板示意，不做真实试衣

**状态：** 采用（待真实素材评审）  
**日期：** 2026-10-18

## 背景

淘宝商品图、自拍照、衣架照片具有不同拍摄角度。即使抠图成功，也无法保证任意衣服图能够自然贴在标准人物上。

## 决策

第一版以标准 2D 人物为中心，服装以预设轮廓模板、主颜色映射展示，真实服装图留在独立卡片中。使用统一逻辑坐标系和服装槽位。

当前技术样例使用 Flutter `CustomPainter` 绘制基础层，目标是验证渲染/点击/状态同步，不承担商品图真实贴合责任。

## 影响

- 可以先实现主要穿搭交互闭环。
- 对复杂领口、袖长、图案、面料质感缺乏准确显示，必须标示“示意”。
- 后续的资产系统需要 `templateId`、`anchorPreset`、`assetVersion` 与 fallback 策略。
- 3D 与真人虚拟试衣属于未来新项目，不能把该决定描述成现有技术的无缝升级。
