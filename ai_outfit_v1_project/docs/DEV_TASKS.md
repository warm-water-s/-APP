## Milestone 3 — 正式 MVP 测试

- 功能/权限/图片/推荐的端到端测试。
- 用户真实衣橱样本、风格推荐的人类评估。
- 网络离线、上传中断、识别失败和数据删除测试。
- 10–20 名目标用户的小规模体验。
- 上线合规和隐私政策评审。

**强制规范：** 无法测试的功能必须标记“未验证”，不要将演示数据与正式功能混淆。所有范围变化同步更新 PRD / UIUX / ADR / CHANGELOG。
